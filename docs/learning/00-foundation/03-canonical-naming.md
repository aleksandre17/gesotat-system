# Canonical naming

Prefix-ები namespace-ს გამოხატავს, არა შემთხვევით შემოკლებას:

- `__raw_` — raw lineage/source records;
- `__ent_` — canonical entity projection;
- `__stat_` — statistical materialization;
- `__cl_` — classifier/reference values;
- `__geo_` — geographic structures;
- `__rel_` — declared relation/binding;
- `__gs_` — platform-wide generic/control metadata.

სახელი ყოველთვის უნდა პასუხობდეს კითხვას: ვინ ფლობს ობიექტს, რა lifecycle აქვს და რომელ layer-ს ეკუთვნის.
