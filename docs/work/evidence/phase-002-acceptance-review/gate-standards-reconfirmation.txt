CANDIDATE D - provider-agnostic abstraction supporting only the lowest common denominator
-----------------------------------------------------------------------------------------
  INVARIANTS        HOLDS: BM-INV-08, BM-INV-01, BM-INV-07. BM-INV-09 catches it for NUMERIC precision
                      only, because that is the one axis DR-006 already fixed

  VERDICT (before)  ACCEPTED - wrongly. HOLE FOUND.
  VERDICT (after)   REJECTED by BM-EC-085: for every capability the canonical model lacks, the reason

  NOTE              The distinction that matters: bounding a DECLARATION by the weakest required provider is
