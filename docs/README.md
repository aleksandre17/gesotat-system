The platform objective is broader than KIDS: KIDS R8 is the first reference profile of a contract-driven, schema-agnostic, multi-site data-product platform. The canonical goal is reusable metadata, relation, quality, publication, serving and audit machinery for arbitrary approved data families.

The current deployed KIDS runtime and acceptance authority is [KIDS R8 Current Status and Acceptance](KIDS-R8-current-status-and-acceptance.md). It supersedes execution counts and handoff status in older R7 documents while preserving their architectural rationale.

Normative architecture is defined by [Final Unified Physical Virtual Contract](final-unified-physical-virtual-contract.md), [API Complete Input Output Contract](api-complete-input-output-contract.md), and [Access and Control Plane Responsibility Model](access-and-control-plane-responsibility-model.md). Historical plans and handoffs remain retained for traceability and are not current runtime evidence.

The complete API capabilities, mechanisms, request/response shapes and schema-agnostic onboarding rules are documented in [API Platform Capabilities and Mechanisms](api-platform-capabilities-and-mechanisms.md).

The complete learning and implementation guide for the Control Plane Meta-Contract, mandatory/additional/optional site profiles, table creation order, columns, relations and programmer questions is [Control Plane and Site Schema Learning Guide](control-plane-and-site-schema-learning-guide.md).

The complete KIDS reference and preserved source extraction are included in the unified documentation package linked above.

Current release identity is `KIDS_PORTAL_V1` revision 8, artifact `platform/apps/geostat/backend/api/kids-portal-v1-canonical-r8-final.accdb`, with migrations 071–074 and the acceptance evidence recorded in the current status document.

For the implementation-ready API handoff (page map, discovery, entity/statistical requests, relation includes, pagination, errors and release checklist), see [KIDS R8 API delivery runbook](kids-r8-api-delivery-runbook.md).
