რისკები და შენიშვნები

high

alias api დუბლია. geostat-api და geostat-api-dev ორივე api-ა geostat-net-ზე, ასე რომ Docker DNS round-robin prod/dev-ს შორის. Edge სრული სახელს იყენებს, მაგრამ ყველა სხვა client-მა geostat-api ან geostat-api-dev უნდა გამოიყენოს; dev alias-ი უნდა მოისილდეს.

medium

Dev API edge-ის უკან არ არის. api.geostat.internal/api/ prod-ზე მიდის. Dev HTTPS ტესტისთვის საჭიროა ცალკე ფსევდო-დომენი (მაგ. api-dev.geostat.internal).

medium

UI-ები geostat-net-ზე არ არიან. prod UI — default bridge, dev UI — საკუთარი ქსელი; edge prod UI-ს ჰოსტის პორტით წვდება.

info

ამ ჰოსტზე ასევე ცხოვრობს geostat-chat-*, geostat-chat-ai-*, statdash-*, trade-*, national-accounts-app — სხვა პროდუქტები, რუკაზე არ შედის.
