GEOSOTAT დოკუმენტაციის სრული პაკეტი

ეს საქაღალდე არის Word და HTML დოკუმენტაციის ერთიანი canonical სივრცე. შესწავლა დაიწყე პირველი ფაილიდან და შემდეგ გადადი სამუშაო გეგმასა და სრულ KIDS reference-ზე.

სწავლის თანმიმდევრობა

  1. გლობალური engineering policy (AGENTS.md) — ყველა ცვლილებისთვის სავალდებულო ხარისხის, უსაფრთხოების, აგნოსტიკურობისა და release gate-ები.
  2. პლატფორმის capability და architecture audit — 2026-09-13 — არსებული მდგომარეობა, maturity scorecard, P0–P3 gap-ები, მექანიზმები და მიღების კრიტერიუმები.
  3. Production operations runbook — bootstrap, preflight, deployment, publication, rollback და archive პროცედურები.
  4. Production preflight script, audit checklist verifier და image provenance verifier — executable release controls.
  5. Remote production evidence — read-only runtime and Compose verification, plus provenance gap.
  6. სრული სისტემური HTML დოკუმენტაცია — ბაზები, planes, contracts, Access, API, KIDS R8, კითხვები და სრული წყაროები.
  7. პლატფორმის სამუშაო და დასრულების გეგმა — სამუშაო პაკეტები, dependencies, acceptance, რისკები და Definition of Done.
  8. KIDS მართვის პანელის სრული reference — აღდგენილი სრული არქიტექტურული და იმპლემენტაციის სპეციფიკაცია.
  9. KIDS-ის სრული ტექსტური პირველწყარო — უცვლელი extraction, რომელიც ინარჩუნებს სრულ ტექსტს.
